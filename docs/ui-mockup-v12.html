자동 생성될 그룹

테이블 템플릿

item_id · CAT1 · CAT2 · CAT3 · Report
item_id는 리포메터의 ALIAS와 같은 값입니다. CAT1이 표를 나누는 기준(표 하나 = 시트 하나)이고, CAT2·CAT3는 세로 병합 계층입니다.
· Report로 한 파일에 여러 리포트를 담고 UI에서 골라 씁니다
· 행 순서가 곧 표시 순서입니다 · 같은 CAT2가 연속되면 자동 병합됩니다
· 평균/산포 전환은 UI 토글로 합니다 (템플릿에 값 컬럼 없음)
· 자릿수는 리포메터 UNIT에서, 붉은 셀은 SPECLOW/SPECHIGH에서 자동으로 결정됩니다
· 컬럼(wafer)은 분석 대상에서 자동으로 정해집니다

Plot 템플릿

page · x · y · order · title1 · title2 · Report · Type · x_name · y_name
· title1 = 페이지 제목 (같은 page의 첫 행에만 적으면 됩니다) · title2 = plot 제목
· order = 페이지 안 위치 1~6, 왼쪽에서 오른쪽 순서 (1·2·3 윗줄 / 4·5·6 아랫줄)
· x·y는 리포메터 ALIAS로 적습니다 · 쉼표로 여러 개를 적으면 순서대로 xy 쌍이 맺어져 한 그림에 겹칩니다
· x_name·y_name은 축 표시 이름 · 비우면 ALIAS + UNIT이 자동으로 붙습니다
· Type: scatter / table / box(예정)
· Report로 한 파일에 여러 리포트를 담습니다 — 테이블 템플릿의 Report와 짝을 이룹니다
· 로그 축과 축 범위 컬럼은 없습니다 — 로그는 item 이름 규칙, 범위는 SPEC∪데이터 ×1.2가 기본이고 필요하면 UI에서 plot마다 바꿀 수 있습니다

리포메터

CATEGORY · ITEMID · ALIAS · ABSOLUTE · SCALE FACTOR · ADDP FORM · UNIT · SPECLOW · SPECHIGH · TARGET
· CATEGORY = REAL(실측) / ADDP(계산) · ADDP는 ADDP FORM에 수식을 적습니다
· 수식의 item 참조는 {ALIAS} · 다른 ADDP를 쓰려면 그 행이 위쪽에 있어야 합니다
· ABSOLUTE = Y면 절대값을 취합니다 (PMOS 전류·Ioff 등) · SCALE FACTOR는 수식 계산 전에 적용됩니다
· SPECLOW·SPECHIGH는 표의 규격 이탈 표시와 plot 축 범위 산정에 쓰입니다 (SPEC∪데이터 ×1.2)
· Std({A},{B},…) = 인자들을 각각 하나의 포인트로 보는 산포 · 엑셀 STDEV(n−1) 기준 · NULL은 빼고 계산

· 축은 alias로 적습니다 · 축라벨이 비면 alias + 단위가 자동으로 붙습니다
· x축 A, B · y축 C, D → (A,C)·(B,D) 두 쌍이 한 그림에 겹칩니다 · 쉼표 개수가 다르면 오류
· 로그 축과 축 범위 컬럼은 없습니다 — 불러온 뒤 기본값은 로그 = item 이름 규칙, 범위 = 규격∪데이터 ×1.2 입니다. 필요하면 UI에서 plot마다 개별로 변경할 수 있고, 바꾼 값은 구성 저장에 함께 남습니다
· 플롯종류: scatter box table
· 불러오면 검증 결과를 행 번호와 함께 먼저 보여줍니다
